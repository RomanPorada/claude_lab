# Навантажувальне тестування

## Запуск
`./loadtest/run.sh http://<адреса> <N> <THINK>`   (використано N=<…>, THINK=<…>)

## Сценарій
- Один віртуальний користувач у циклі: 1 запис (POST /orders) і 9 читань (список і окремий елемент каталогу атомів і молекул, щойно створене замовлення, дані автора /auth/me, список моїх замовлень).
- Фази: наростання 0 → N за 2 хв 30 с; N користувачів 5 хв; спад до 0 за 2 хв.
- N підібрано експериментально: <чому саме так, при меншому N CPU не перетинав 60%>.
